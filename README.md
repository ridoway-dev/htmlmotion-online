# HTMLMotion — Claude HTML to MP4 Video Converter (Micro-SaaS)

> **HTMLMotion** converts HTML & CSS animations generated by **Claude Design** or **Claude Motion** into studio-grade, downloadable MP4 videos using Playwright (Chromium) and FFmpeg.

---

## 🚀 Overview

Claude 3.5 Sonnet and Claude Motion can generate beautiful web animations using pure CSS keyframes, SVG, or HTML5 Canvas. However, video creators, social media managers, and marketers need these animations in **MP4 format** for YouTube, Instagram Reels, TikTok, and presentations.

**HTMLMotion** solves this without rebuilding any animation engine:
1. **User Uploads**: Upload an `.html` file, a `.zip` archive, or paste raw Claude code.
2. **Interactive Preview**: Sandboxed real-time iframe preview with aspect ratio framing (16:9 Landscape, 9:16 Shorts/Reel, 1:1 Square, etc.).
3. **Chromium Headless Capture**: Playwright loads the HTML animation in an isolated browser sandbox and records high-speed frames.
4. **FFmpeg MP4 Encoding**: Transcodes frames into pristine H.264 MP4 at 30 or 60 FPS with optimal web compatibility (`yuv420p`, `faststart`).
5. **Instant Download**: Direct one-click download with zero watermarks.

## ⚡ How to Run Locally (Phase 1 MVP)

### 1. Requirements
- Node.js 18+ (tested on Node.js v24)
- Playwright Chromium (`npx playwright install chromium`)

### 2. Install & Start
```bash
# Install dependencies
npm install

# Install Chromium for Playwright
npx playwright install chromium

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🗺️ Roadmap to Production SaaS

### Phase 1 — Local MVP (Completed & Active)
- Zero server cost.
- Direct Chromium capture + local FFmpeg encoding.
- Verifies the end-to-end converter logic on your computer.

### Phase 2 — Online Micro-SaaS
- **Frontend**: Deploy on Vercel.
- **Render Worker**: Dedicated Hetzner/DigitalOcean VPS running Dockerized Chromium + FFmpeg.
- **Job Queue**: Redis + BullMQ (handles concurrent renders safely without server throttling).
- **Storage**: Cloudflare R2 (zero egress fees for fast MP4 downloads).
- **Database**: Supabase / PostgreSQL for user accounts and render logs.

### Phase 3 — Monetization & Launch
- **Free Tier**: 3 renders/day, up to 1080p, 30 FPS, optional subtle watermark.
- **Pro Tier ($9 - $19/mo)**: Unlimited exports, 60 FPS, 4K UHD, no watermark, priority rendering queue.
- **Custom Branding**: Add logos, sound effects/audio tracks, and custom font packs.
